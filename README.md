# Game Vault 

## Descripción
Sitio web **Game Vault**: catálogo y plataforma de videojuegos desarrollada como práctica de desarrollo web. El proyecto fue elaborado con herramientas modernas como Vite, aplicando conocimientos de estructuración, diseño y publicación de sitios en línea.

## Contenido del proyecto
- `index.html` → Página principal del sitio
- Carpeta `assets/` → Estilos, scripts y recursos visuales

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
- Vite (compilación y despliegue)
